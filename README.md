# BigOne

BigOneApp

## Project Notes (transcribed from handwritten brief)

### Purpose
- Build an **RWB Dashboard + Warehouse** hub so stakeholders can see where merchandise is.
- Intended users include admins (e.g., Rob, Cynthia), warehouse receivers/managers, designers, and clients.

### Core workflow
- Receiver/manager should be able to take photos using an iPad or phone camera.
- App should read shipping details (designer/company name, client name, and related details).
- App should generate a **warehouse label** for each item/package including:
  - Client name (prominent/bold)
  - Designer/firm name
  - Other order-receipt details
  - Barcode or QR code for tracking

### Tracking requirements
- Track each package through statuses such as:
  - Inspection
  - Warehouse location/storage area
  - Staged for installation
  - Loaded
  - Delivered
  - Rejected (if applicable)
- Every package should have its own unique warehouse label and scannable code.

### Accounts and access
- Each user should have an individual account.
- Accounts are approved by an admin.
- Admin sends initial login details.
- A secure but simple "designer hub" should show:
  - Paperwork received for each piece
  - Photos
  - Current status

### Document/photo capture
- App should allow photos of:
  - Item inspection
  - Box/packaging as received
  - Forms and paperwork received
- Document capture should support converting photos into scanned PDFs to support a paperless process.

### Additional ideas from notes
- Dashboard should include easy shipment designating/splitting or completion status by customer/order.
- A complete delivery module and account controls are desired.
- System should support adding notes for routing/status and analytics for proof of delivery.
- Suggested architecture in notes references cloud deployment and role-based access.
- Mobile access was noted as helpful for installation teams.

### Rough UI sketch elements captured
- Two dock areas ("Dock 1" and "Dock 2")
- Main staging area and receiving area
- Supplies area
- Status strip/list along one side
- Possible map/flow-style warehouse layout view
